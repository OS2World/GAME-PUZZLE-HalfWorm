# HalfWorm for OS/2

A two-player action game for OS/2 Presentation Manager. Two worms compete
on a game board, eating apples for special powers. The last worm standing wins.

Version 0.9 - OpenWatcom port by OS2World community.

![HalfWorm ScreenShot](/doc/HalfWorm.png)

## FEATURES

- Two-player worm action game with DIVE graphics and MMPM/2 sound effects
- Apple power-ups (speed, fire rate, missile types, homing, bouncing, and more)
- Elements drawn at 4x4 screen pixels; the board size can be changed (Options - Board Size)
- Menus and online help (IPF, F1) in English, Spanish, Dutch, German, French and Italian
- Pause Game, Background Run, Frame Controls, double window and saved settings
- 12 sound effects, synthesized by `tools\gen_sounds.py`

## HOW TO PLAY

Choose New Game (Ctrl+N or F2). Each player turns the worm counterclockwise or
clockwise and fires missiles; the worm always moves forward and the board wraps at
the edges. Eat apples for special abilities (some help, some hurt). A worm dies when
it hits a worm or is hit by a missile. The last worm standing wins the round.

## DEFAULT KEYS

Game keys (change them with Options - Keys):

| Action                    | Player 1 | Player 2    |
|---------------------------|----------|-------------|
| Rotate counterclockwise   | A        | Left arrow  |
| Rotate clockwise          | D        | Right arrow |
| Fire                      | W        | Up arrow    |

Menu shortcuts:

| Key          | Action                                             |
|--------------|----------------------------------------------------|
| Ctrl+N or F2 | New Game                                           |
| Ctrl+P       | Pause Game / resume                                |
| Ctrl+Q       | Quit Game (back to the title screen)               |
| Ctrl+X or F3 | Exit                                               |
| Ctrl+D       | Double window (4x4 pixel elements) on / off        |
| Ctrl+B       | Background Run (keep running without the focus)    |
| Ctrl+F       | Frame Controls (hide / show title bar and menu)    |
| F1           | Help                                               |

## REQUIREMENTS

OS/2 Warp 4 or ArcaOS 5.x with DIVE; MMPM/2 for the sound effects; a 256 colour
display mode is recommended.

## COMPILE TOOLS

OpenWatcom C (wcc386 / wlink / wrc / wmake)

### Build Instructions

Run on ArcaOS or OS/2 Warp 4 with OpenWatcom installed:

```
compile-wat.cmd
```

Or manually:

```
wmake -f makefile.wat
```

The executable is placed in `bin\HalfWorm.exe` and the online help files (built with `wipfc`) in `bin\help\HalfWorm_xx.hlp`; keep the `help` folder next to the exe.

## FOLDER STRUCTURE

```
src\        Source files (C, RC, DEF, H)
bin\        Build output (exe, obj, res, help\*.hlp)
doc\        Documentation (Readme, Changelog, License)
sounds\     Sound effects (WAV, generated by tools\gen_sounds.py)
tools\      Helper scripts
help\       IPF help sources, one per language (en, es, nl, de, fr, it)
legacy\     Original source archive
```
